# ダウンロードした画像をマップのアイコンに使う手順

マップのアイコンは、標準では `src/client/components/pixel-icons.ts` に定義した 32×32 のドット絵を使っている。
`assets/icons/` に画像を置くと、そのアイコンだけがダウンロードした画像に置き換わる。コードの変更は不要。

---

## 1. 利用規約を確認する

画像をダウンロードする前に、配布元の利用規約で次を確認する。

- Web ゲーム・Web アプリでの利用が認められているか
- 商用利用の可否（将来、公開・収益化する可能性がある場合）
- 加工（サイズ変更・色変更）の可否
- 再配布の扱い（素材をリポジトリに含めて公開すると再配布に当たる場合がある）
- クレジット表記の要否

再配布が禁止されている素材を使う場合は、手順 5 を参照し、リポジトリに含めないようにする。

## 2. 画像を用意する

- 形式: PNG / GIF / SVG / WebP
- サイズ: 32×32 ピクセル推奨（マップの1マスが 32px）
  - サイズが違っても縦横比を保って1マスに収まるよう表示される
  - 拡大縮小時はドット絵がぼやけないよう最近傍補間（`image-rendering: pixelated`）で表示される
- 背景は透過推奨（マスの背景色が透けて見える）

## 3. ファイル名を決めて assets/icons/ に置く

ファイル名を「アイコン名.拡張子」にして `assets/icons/` に置く。

```
assets/
└── icons/
    ├── shop.png
    └── townhall.gif
```

使えるアイコン名:

- `shop`: お店
- `job`: 職業安定所
- `school`: 学校
- `gym`: トレーニングジム
- `cafeteria`: 食堂
- `casino`: 賭場
- `realestate`: 不動産屋
- `bank`: 銀行
- `blackmarket`: 闇市場
- `izakaya`: 居酒屋
- `townhall`: 役場
- `house`: 購入済みの土地に建つ一軒家
- `mansion`: 購入済みの土地に建つマンション
- `store_convenience`: 店舗（コンビニ）
- `store_restaurant`: 店舗（レストラン）
- `store_bar`: 店舗（バー）
- `grass`: 空き地の草むら

店主のアイコン（施設画面に 64px で表示）:

- `npc_shop`: お店の店主 / `npc_job`: 職業安定所の相談員 / `npc_school`: 学校の先生
- `npc_gym`: ジムのトレーナー / `npc_cafeteria`: 食堂のおばちゃん / `npc_casino`: 賭場の壺振り師
- `npc_realestate`: 不動産屋の社長 / `npc_townhall`: 役場の職員 / `npc_izakaya`: 居酒屋の大将
- `npc_bank`: 銀行の行員 / `npc_blackmarket`: 闇の商人
- `npc_soup`: 炊き出しおじさん

注意:

- 上記以外の名前のファイルは使われない（エラーにもならない）
- 同じアイコン名で拡張子違いのファイルを複数置かない（どちらが使われるかは保証しない）
- `house` / `mansion` / `store_*` を画像に置き換えると、屋根の色による「自分の土地（赤）/ 他の住民の土地（橙）」の区別がなくなる

## 4. 表示を確認する

1. `npm run dev` で起動し、http://localhost:5173 を開く
   - 起動中に画像を追加した場合は、ブラウザをリロードする。反映されなければ `npm run dev` を再起動する
2. ホーム画面の「町の地図」と、不動産屋の地図でアイコンが置き換わっていることを確認する

本番用のビルド（`npm run build`）では、画像は自動でビルド結果に含まれる（4KB 未満の画像は JS に埋め込まれ、それ以上はファイル名にハッシュが付いて `dist/assets/` に出力される）。

## 5. 再配布が禁止されている素材の場合

素材をリポジトリに含めたくない場合は、`.gitignore` に次を追加する。

```
assets/icons/*
!assets/icons/.gitkeep
```

この場合、画像は各自の環境にだけ置かれる。別の環境やデプロイ先では、同じ手順で画像を配置する必要がある（配置しなければドット絵が表示される）。

## 元のドット絵に戻す

`assets/icons/` から該当の画像ファイルを削除する。

## 仕組み

`pixel-icons.ts` が Vite の `import.meta.glob` で `assets/icons/*.{png,gif,svg,webp}` を読み込み、ファイル名（拡張子を除く）をアイコン名として対応付けている。画像がないアイコンは、ドット絵の SVG を表示する。
