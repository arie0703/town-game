# TOWNゲーム 実装計画（task）

要件は [spec.md](spec.md) を参照。本書は MVP を実装するためのタスクリスト。

---

## 進め方

- フェーズ順に実装する。各フェーズの終わりにローカルで動作確認できる状態にする
- 1タスク = 1PR 程度の粒度を目安にする
- ゲームロジック（計算・判定）は `src/server/game/` に関数として切り出す
- テストコードは実装しない（動作確認はブラウザで手動で行う）
- Lint / Formatter は導入しない（`tsc` の型チェックのみ）
- 数値は仮置きで実装し、Phase 10 でまとめて調整する

### 構成

- 1パッケージ構成（npm workspaces は使わない）
- フロントエンドは SPA（`index.html` 1枚 + hash ルーティング `#/home` 等。ルーターライブラリは使わない）
- サーバー（Hono）は JSON API のみを提供する。開発時は Vite の proxy で `/api` をサーバーへ転送する
- マスタデータ（職業・アイテム・メニュー・マップ）は TypeScript の定数ファイルで持ち、DB には入れない

```
/
├── docs/                 # spec.md / task.md
├── index.html            # SPA のエントリ
├── src/
│   ├── client/           # フロントエンド
│   │   ├── main.ts       # 起動・hash ルーター
│   │   ├── api.ts        # API クライアント（fetch のラッパー）
│   │   ├── pages/        # 画面ごとの描画処理
│   │   └── style.css
│   ├── server/           # バックエンド（Hono）
│   │   ├── index.ts
│   │   ├── routes/       # API ルート
│   │   ├── game/         # ゲームロジック
│   │   └── db.ts         # DB 接続・テーブル作成
│   └── shared/           # client / server 共通
│       ├── types.ts      # 型定義
│       ├── config.ts     # 定数（初期値・回復量・上限など）
│       └── master/       # マスタデータ（職業・アイテム・メニュー・マップ）
├── package.json
├── tsconfig.json
└── vite.config.ts
```
